# New to Awesome Game Mashups

Week ending 2026-10-19. These are additions to the index, not necessarily new releases.

- **[VEmu](https://github.com/bailo167/awesome-game-mashups#project-vemu)** — Adds libretro-backed consoles and handhelds to Voices of the Void that play your own ROMs inside the game. (Released · Code available)
- **[SBCraft](https://github.com/bailo167/awesome-game-mashups#project-sbcraft)** — Runs real Minecraft Java alongside FNAF: Security Breach and blends its blocks, items and mobs into the game. (Released · Code available · Experimental)
- **[Gorilla Passthrough (Gorilla Tag x Minecraft)](https://github.com/bailo167/awesome-game-mashups#project-gorilla-passthrough)** — Plays Gorilla Tag in VR as a gorilla inside a real running Minecraft world. (Released · Code available · Experimental)

- **[BlockBoy / BlockBoy Arcade](https://github.com/bailo167/awesome-game-mashups#project-blockboy)** — Server-side Game Boy and Game Boy Color emulator mod for Minecraft, playable on in-world maps or arcade machines. (Released · Code available)
- **[RetroConsole (libretro consoles in Minecraft)](https://github.com/bailo167/awesome-game-mashups#project-retroconsole)** — A NeoForge mod that embeds libretro emulators in Minecraft 1.21.1 so players can run console games on in-world TV walls, with server-side emulation streamed to nearby players. (Released · Code available · Experimental)
- **[Hollow Sols (Nine Sols in Hollow Knight's Godhome)](https://github.com/bailo167/awesome-game-mashups#project-hollow-sols)** — A two-process BepInEx passthrough that lets Nine Sols' Yi fight Hollow Knight's 44 Godhome boss encounters with his native movement and combat. (Released · Code available · Experimental)
- **[SM64BS (Mario 64 in Beat Saber)](https://github.com/bailo167/awesome-game-mashups#project-sm64bs)** — Puts a playable Super Mario 64 Mario into Beat Saber's VR menu and game scene; pre-release builds, no licence file. (Released · Code available)
- **[Retro Machines (Game Boy in Minecraft)](https://github.com/bailo167/awesome-game-mashups#project-retro-machines)** — Embeds a modified rboy Game Boy emulator in a Minecraft Fabric mod so you can load your own Game Boy ROMs in-game; a 2023 prototype. (Released · Experimental)
- **[LethalMario64 (Mario 64 in Lethal Company)](https://github.com/bailo167/awesome-game-mashups#project-lethalmario64)** — A Lethal Company suit mod that turns the player into the real Super Mario 64 Mario via libsm64; released on Thunderstore, no linked source. (Released)
- **[HalfCraft (Minecraft in Half-Life)](https://github.com/bailo167/awesome-game-mashups#project-halfcraft-half-life)** — Bridges a real Minecraft Java instance into Half-Life's Black Mesa campaign through shared memory; source only, no release. (Code available · Experimental)
- **[Skyrim Shouts and Dragons in Fallout 4 (Glenny)](https://github.com/bailo167/awesome-game-mashups#project-skyrim-shouts-fallout-4-glenny)** — Creator videos show Skyrim's dragon shouts and dragons running in Fallout 4; no download yet. (In development · Video only)
- **[Knee-Deep in the Mines](https://github.com/bailo167/awesome-game-mashups#project-knee-deep-in-the-mines)** — Rebuilds DOOM's maps, monsters, weapons and sounds from the WAD as playable Minecraft worlds. (Code available · Experimental)
- **[Mirror's Edge Movement in GTA San Andreas (Faith Runner)](https://github.com/bailo167/awesome-game-mashups#project-faith-runner-gta-sa)** — SavegameNostalgia's video shows CJ moving with Mirror's Edge parkour physics via a Rust movement core; no bridge code is public. (Video only · Unconfirmed)

- **[TempleMaps](https://github.com/bailo167/awesome-game-mashups#project-templemaps-hytale)** — Runs Windows 95 and FreeDOS on a Hytale world map through the JPC x86 emulator. (Code available · Experimental)
