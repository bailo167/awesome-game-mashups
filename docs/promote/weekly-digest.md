# New to Awesome Game Mashups

Week ending 2026-11-01. These are additions to the index, not necessarily new releases.

- **[MineDoom](https://github.com/bailo167/awesome-game-mashups#project-minedoom)** — Runs id Software's original 1997 linuxdoom C engine natively inside Minecraft's process via JNI, started from a Doom Block. (Released · Code available)
- **[DoomCraft (ChromusMaster)](https://github.com/bailo167/awesome-game-mashups#project-doomcraft-chromusmaster)** — Adds a craftable CRT television to Minecraft that shows an isolated LZDoom process running player-supplied WADs. (Released · Code available)
- **[The Doom Within (Doom in World of Warcraft)](https://github.com/bailo167/awesome-game-mashups#project-wow-doom-within)** — World of Warcraft addon that emulates a RISC-V Linux machine in Lua to run Doom. (Code available · Experimental)
- **[smolnes-nut](https://github.com/bailo167/awesome-game-mashups#project-smolnes-nut)** — Ports the smolnes NES emulator to Squirrel so it runs inside Portal 2's VScript, with a (barely playable) in-map demo. (Code available · Experimental)
- **[Computerraria (RISC-V computer in Terraria)](https://github.com/bailo167/awesome-game-mashups#project-computerraria)** — A RISC-V (rv32i) computer built in Terraria's wiring system; related precursor to in-game computers. (Code available · Related)
- **[AC6-FXR-DOOM-POC (Doom in Armored Core VI)](https://github.com/bailo167/awesome-game-mashups#project-ac6-fxr-doom)** — Rust DLL that runs Doom inside Armored Core VI and shows its frames on a 160x100 screen of 16,000 effect particles. (Released · Code available · Demo)
- **[WowFC](https://github.com/bailo167/awesome-game-mashups#project-wowfc)** — World of Warcraft addon that runs NES/Famicom games in a draggable in-game window. (Released · Code available)
- **[RCECoaster (Doom in RollerCoaster Tycoon)](https://github.com/bailo167/awesome-game-mashups#project-rcecoaster-doom)** — Security exploit that makes a crafted RollerCoaster Tycoon (1999) save file take over the game's thread and run Doom in its window. (Code available · Demo)
- **[ViceAbyss (Vice City in Subnautica 2)](https://github.com/bailo167/awesome-game-mashups#project-viceabyss)** — Play Subnautica 2 as Tommy Vercetti, with GTA Vice City running in the background to supply live animation, HUD and weapons. (Released · Experimental)
- **[Valheim GameBoy](https://github.com/bailo167/awesome-game-mashups#project-valheim-gameboy)** — A BepInEx mod that adds a Game Boy emulator to Valheim. (Released · Experimental)
- **[Playable GameBoy (Project Zomboid)](https://github.com/bailo167/awesome-game-mashups#project-playable-gameboy-zomboid)** — Runs Game Boy ROMs through the LuaGB emulator inside Project Zomboid. (Released · Experimental)
- **[LC DOOM (Lethal Company)](https://github.com/bailo167/awesome-game-mashups#project-lethal-company-doom-cryptoc1)** — Play DOOM on the ship's terminal in Lethal Company, via a BepInEx mod. (Released)
- **[balatro-doom (KittyShopper)](https://github.com/bailo167/awesome-game-mashups#project-balatro-doom-kittyshopper)** — A work-in-progress Steamodded mod that loads a doomgeneric build as a native Lua library inside Balatro. (Code available · Experimental)
- **[VegasCraft (benedettoscala)](https://github.com/bailo167/awesome-game-mashups#project-vegascraft-benedettoscala)** — Lets you play Fallout: New Vegas with Minecraft Java's movement, inventory, blocks and combat running alongside it. (Released · Code available · Experimental)
- **[Retrocraft (libretro consoles in Minecraft)](https://github.com/bailo167/awesome-game-mashups#project-retrocraft)** — A Fabric mod that adds handhelds, home consoles, arcade cabinets and CRT televisions to Minecraft 1.21.1, each backed by a real libretro emulator core. (Released · Code available · Experimental)
- **[Left4Craft2 (Minecraft in Left 4 Dead 2, ShadowBlade83)](https://github.com/bailo167/awesome-game-mashups#project-left4craft2)** — Lets you play Left 4 Dead 2 as Steve, with Minecraft physics, HUD and blocks while L4D2 runs the world and infected. (Released · Code available · Experimental)
- **[GtaCraft (GTA V x Minecraft, gta5craft)](https://github.com/bailo167/awesome-game-mashups#project-gtacraft-gta5craft)** — Connects GTA V Story Mode and Minecraft Java so you can switch between a Minecraft Overworld and a Minecraft mirror of Los Santos and drive on block terrain. (Released · Code available · Experimental)
- **[GorillaCraft (Gorilla Tag locomotion in VR Minecraft)](https://github.com/bailo167/awesome-game-mashups#project-gorillacraft)** — Lets you play Minecraft in VR as a Gorilla Tag gorilla, with Gorilla Tag's arm-swing movement driven across Minecraft's blocks. (Code available · Experimental)
- **[Bannerlord x Minecraft Passthrough](https://github.com/bailo167/awesome-game-mashups#project-bannerlord-minecraft-passthrough)** — Puts Minecraft's Steve into Mount & Blade II: Bannerlord battles, with Minecraft combat, blocks and inventory running side by side. (Released · Code available)
